# ✅ To-Do App

A clean, responsive task manager built with vanilla JavaScript, HTML5, and CSS3. Add, edit, complete, and delete tasks, and your list stays saved between sessions using `localStorage`.

![Preview](screenshot.png)

🔗 **Live Demo:** [Mayankrajbhargit.github.io/todo-app](https://Mayankrajbhargit.github.io/todo-app)

## ✨ Features

- Add, edit, and delete tasks
- Mark tasks as complete or incomplete
- Data persists across page reloads with `localStorage`
- Responsive design for desktop and mobile
- Lightweight, with no dependencies and no build step

## 🛠️ Tech Stack

| Technology | Purpose |
|------------|---------|
| HTML5 | Structure and semantic markup |
| CSS3 | Styling and responsive layout |
| JavaScript (ES6+) | DOM manipulation, events, Web Storage API |
